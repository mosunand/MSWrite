# 2026-09-28 稳定性、性能与默认命名修复

已生成 Release 发布程序：`dist/Mswrite/Mswrite.exe`。

## 默认命名

- 未命名 Markdown 保存和 PDF/HTML/Word 导出共用原生标题提取逻辑。
- `**AI生成多媒体内容安全与可信溯源**` 建议使用 `AI生成多媒体内容安全与可信溯源.md` / `.pdf`。
- 过滤标题、粗体、公式定界符、引用和列表等格式；跳过空白、纯标记行、注释、YAML 元数据和代码围栏块。
- 处理 Windows 非法字符、保留设备名、末尾空格/点及过长文件名；截断时不拆开 emoji 的 UTF-16 代理对。
- 手动指定过的文件名继续保留。自动保存遇到同名文件会添加序号。
- 刚修改标题立即保存时读取当前内容；导出使用与 HTML 快照配套的标题，避免采用旧标题。

## 修复的问题

- 标题查询等待超时后，迟到的回调不再访问已经销毁的局部变量和事件循环。
- WebView2 控制器关闭过程中可能同步完成脚本回调，新增销毁状态检查，阻止回调访问正在销毁的对象。
- 原生快捷键动作延后到 WebView2 同步回调返回后执行，避免在回调中进入模态对话框或关闭控制器。
- 保存、导出、插图、链接和替换对话框不再跨事件循环保留可失效的标签数组引用。
- 导出请求绑定来源标签和请求编号；当前导出完成前不接受第二次导出，避免串文档和串格式。
- 渲染等待计时器绑定请求，处理 PDF 导航失败和 PrintToPdf 立即失败；HTML/Word 使用原子写入并检查写入结果。
- UTF-16 文档从解码后的文本检测 CRLF，修复错误改变行尾的问题。
- 日志写入加锁，并对日志文件大小做轮转限制。

## 性能改动

- 文档标题后台更新最多处理开头 64 KiB，避免每次输入都拆分全文。
- 光标统计与正文更新使用独立计时器，光标移动不再取消标题和大纲刷新。
- 关闭行号时，代码布局只读取当前编辑块；复用未改变的高亮结果，清理旧滚动监听。
- 超过 32000 字符的代码块跳过自定义重复高亮，原始代码保留。
- 实测同一代码块连续执行 8 次布局刷新，自定义高亮调用次数为 0。
- 主程序由原先未指定构建类型改为 Release 构建。
