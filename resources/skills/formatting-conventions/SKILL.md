# Document formatting conventions

When writing into the Mswrite document, follow these conventions:

- NEVER use `>` blockquotes in the document. Mswrite renders them as a
  vertical bar with faded text, which the user considers broken output.
  To highlight a key point, use a bold lead-in instead, for example:
  `**要点**:具体内容……`, or a separate short paragraph.
- Keep table cells short. Write each formula in a table cell as ONE
  complete `$...$` span; never split one formula into several fragments
  or mix plain text with fragments inside a cell.
- Headings use `##`/`###` (never skip to `####` right after the title),
  one blank line between paragraphs, and `---` only as a standalone
  divider line, never at the very start of the document.
